# Zuka News 🌸 宝塚歌劇ニュースまとめ

宝塚歌劇団の公式ホームページ、主要スポーツ新聞、舞台ニュースサイト、ファンブログなどの最新情報を自動収集し、スマートフォンで快適かつ優雅にチェックできるWebアプリです。

**GitHub Pages** と **GitHub Actions** を活用することで、**サーバー費用0円（完全無料）** で永久運用が可能です。

---

## ✨ 主な特徴

- **洗練されたエレガント＆フェミニンなデザイン**:
  - スミレ色、ローズピンク、シャンパンゴールドを基調とした、毎日開きたくなる上質なUI。
- **組別・トップスター別分類**:
  - 🌸 花組、🌙 月組、❄️ 雪組、⭐ 星組、🪐 宙組、💎 専科の各組タブ。
  - 各組の現役トップスター（永久輝せあ、星空美咲、鳳月杏、天紫珠李、朝美絢、音彩唯、暁千星、詩ちづる、桜木みなと、春乃さくら等）によるクイック絞り込み。
- **写真付きニュースカード**:
  - 記事画像（または組シンボルをあしらったエレガントなプレースホルダー）を美しく表示。
- **未読・既読管理**:
  - 未読記事にはピンクの「NEW」バッジ。タップして閲覧すると既読化。
  - 「未読のみ表示」フィルターや「すべて既読にする」ワンタップ機能付き。
- **セキュリティ（パスコード認証）**:
  - 初期パスコード：`0310`
  - パスコードを知っている人だけが閲覧可能。ログイン維持機能付き。
- **お気に入り＆検索機能**:
  - 気に入った記事を保存できるブックマーク機能。
  - スター名や演目名でリアルタイムに絞り込める検索機能。

## 🚀 GitHubでの完全無料 公開・運用手順

### 1. GitHubリポジトリを作成してコードをプッシュ

ターミナル（またはお好みのGitツール）で以下を実行します：

```bash
cd /Users/yasuyuki/Documents/Antigravity/ZukaNews

# Git初期化
git init
git add .
git commit -m "feat: initial release of Zuka News"

# GitHubで「ZukaNews」というリポジトリを作成した上で：
git branch -M main
git remote add origin https://github.com/<あなたのユーザー名>/ZukaNews.git
git push -u origin main
```

---

### 2. GitHub Pagesを有効化（サイトのURLを発行）

1. GitHubのリポジトリページを開き、上部メニューの **「Settings」** をクリックします。
2. 左サイドバーの **「Pages」** をクリックします。
3. **Build and deployment** の設定：
   - **Source**: `Deploy from a branch` を選択
   - **Branch**: `main` ブランチ、フォルダは `/ (root)` を選択
4. **「Save」** をクリックします。
5. 数分後、ページ上部にサイトのURLが表示されます：
   `https://<あなたのユーザー名>.github.io/ZukaNews/`

---

### 3. GitHub Actionsの書き込み権限を許可（自動更新の設定）

GitHub Actionsが定期的にニュースを収集して `data/news.json` を更新・コミットできるように設定します。

1. リポジトリの **「Settings」** をクリックします。
2. 左サイドバーの **「Actions」** > **「General」** をクリックします。
3. ページ下部の **「Workflow permissions」** セクションまでスクロールします。
4. **「Read and write permissions」**（読み取りおよび書き込み権限）にチェックを入れます。
5. **「Save」** をクリックして保存します。

> [!TIP]
> これで、**4時間ごと**（1日6回）に自動で最新ニュースが収集され、サイトが自動更新されます！

---

### 4. すぐに最新ニュースを取得したい場合（手動更新）

1. GitHubリポジトリの **「Actions」** タブをクリックします。
2. 左側のワークフロー一覧から **「Update Takarazuka News」** を選択します。
3. 右側の **「Run workflow」** ボタンを押し、緑色の **「Run workflow」** をクリックします。
4. 数十秒で最新のニュースが取得・反映されます。

## 📱 スマホのホーム画面に追加してアプリ化する方法

### iPhone (Safari)
1. 発行されたGitHub PagesのURL（`https://...`）にアクセスします。
2. 画面下の **「共有（上矢印四角）」** アイコンをタップします。
3. **「ホーム画面に追加」** を選択し、右上の「追加」をタップします。
4. ホーム画面に専用アイコンが作成され、ネイティブアプリ感覚でワンタップ起動できます。

### Android (Chrome)
1. ChromeでURLにアクセスします。
2. 右上のメニュー（3点リーダー）をタップします。
3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップします。
